📝 PAT 生成步骤（只需做一次）：
1. 打开 https://github.com/settings/tokens/new
2. Note（备注）随便填：比如 "9178gg 后台"
3. Expiration（过期时间）选 No expiration（永不过期）
4. 勾选 repo 这一大项（第一个复选框）
⚠️ 如果用的是「细粒度令牌」(Fine-grained token)：
  → Repository access 必须包含 Xjrxjr/9178gg
  → Permissions → Repository permissions → Contents 必须选 Read and write
5. 滚到最下面点绿色 Generate token
6. 复制那串 ghp_xxxxxxxxxxxx 粘贴到上面框里
仓库：Xjrxjr/9178gg（分支：检测中...）

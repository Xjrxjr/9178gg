4. 勾选 repo 这一大项（第一个复选框）
⚠️ 如果用的是「细粒度令牌」(Fine-grained token)：

  → Permissions → Repository permissions → Contents 必须选 Read and write
5. 滚到最下面点绿色 Generate token
6. 复制那串 ghp_xxxxxxxxxxxx 粘贴到上面框里

🏗️ 团队管理（开关 + 自定义名字/图标/颜色 + 排序）

· 每个团队可自定义：开关（绿色 ON=对外显示 / 灰色 OFF=隐藏）、Emoji 图标、中文名、英文名（可选）、主题颜色
